# wackypicasso

Wackypicasso is an AI-driven photo storage and editing tool for the everydayperson. It using [Akave](https://www.akave.ai/) for storage on the [Filecoin](https://filecoin.io/) network.

An Akave JS wrapper has been deployed at codegarage.cloud:8000 to provide a RESTful endpoint for storing and retrieving files.

![](./img/screenshot.png)

## Integrations

This app is using Pexels web API to browse and download images on the web. You are also allowed to upload photos from your device

Akave for storing and retrieving from Filecoin network

Lilypad for inference and AI-driven photo edits. This part will be integrated once we are able to finalise the Lilypad module for receiving image+text inputs
